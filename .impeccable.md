## Design Context

### Users
Developers and ops engineers monitoring autonomous AI coding agent pipelines in real-time.
They need at-a-glance status of active sessions, agent health, cost/token burn, and pipeline
phase progress. They check frequently (every few minutes) and need instant comprehension
without deep navigation.

### Brand Personality
Precise, calm, instrument-grade. Three words: mechanical, trustworthy, uncluttered.
The interface should feel like a mission control console — confident and quiet, not flashy.

### Aesthetic Direction
- **Theme**: Dark (required for extended monitoring sessions in low-light environments)
- **Tone**: Utilitarian, dense, information-first. NOT decorative or playful.
- **Anti-references**: Generic AI dashboards with indigo glows, glassmorphism, floating mascots,
  identical card grids, hero metric layouts. The current design has ALL of these tells.
- **References**: Linear's density, Vercel's status page clarity, Grafana's information packing.

### Design Principles
1. **Density over decoration** — every pixel should convey data, not ambiance
2. **Quiet confidence** — muted palette with one sharp accent for state changes, never glows
3. **Progressive disclosure** — surface 4 key metrics first, reveal depth on interaction
4. **Accessible by default** — WCAG AA contrast, keyboard navigation, screen reader support
5. **Micro-animations only for state** — pulse for active, fade for transitions, nothing decorative
